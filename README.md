# AG News Classification with BiLSTM

Учебный проект по классификации текстов на датасете [AG News](https://huggingface.co/datasets/fancyzhx/ag_news).

В проекте реализован классификатор на основе **BiLSTM** с предобученными **Word2Vec / FastText embeddings**.

В процессе работы были опробованы различные варианты токенизации, pooling, длины последовательности, размера hidden state, dropout, оптимизатора и learning rate scheduler.

## Цель проекта

Познакомиться с задачей классификации текстов и на практике реализовать
полный pipeline:

`текст → токенизация → vocabulary → embeddings → BiLSTM → классификация`

Также посмотреть, как различные настройки модели влияют на качество
классификации.

## Описание данных

**Датасет:** AG News

**Количество классов:** 4

| Label | Category |
| ----: | -------- |
|     0 | World    |
|     1 | Sports   |
|     2 | Business |
|     3 | Sci/Tech |

Для обучения используется исходный train-набор AG News, разделённый на:

* **90%** — training set
* **10%** — validation set

Test-набор используется отдельно и не участвует в подборе гиперпараметров.

Разбиение выполняется с фиксированным `random_state=42` и стратификацией по классам.

## Архитектура модели

Основная модель:

```text
Input text
    ↓
Tokenization
    ↓
Vocabulary
    ↓
Pre-trained Embedding (300d)
    ↓
Dropout
    ↓
Bidirectional LSTM
(hidden size = 128)
    ↓
Attention Pooling
    ↓
Dropout
    ↓
Linear
    ↓
4 classes
```

## Обработка данных

Тексты приводятся к нижнему регистру и токенизируются с помощью регулярных выражений.

Дополнительно:

* удаляются выбранные stop words;
* числовые значения нормализуются;
* строится vocabulary только по training set;
* слова с частотой `< 2` не добавляются в vocabulary;
* максимальный размер vocabulary ограничен `30,000`;
* неизвестные слова отображаются в `<unk>`;
* используется `<pad>` для padding.

### Dynamic Padding

Padding выполняется динамически внутри batch.

Это позволяет не дополнять каждый текст до глобального `max_len`, а использовать максимальную длину только среди последовательностей текущего batch.

Для LSTM дополнительно создаётся mask, позволяющая игнорировать padding при attention pooling.

## Pre-trained Embeddings

В проекте рассматриваются два типа предобученных embeddings:

### Word2Vec

```text

```

### FastText

```text

Предобученные вектора используются для инициализации матрицы эмбеддингов.

```

В первом случае эмбеддинги остаются фиксированными, во втором — дообучаются вместе с моделью.

## Pooling

В процессе экспериментов рассматривались различные способы агрегации выходов BiLSTM.

### Max Pooling

Выбирается максимальное значение каждого скрытого слоя измерения по временной оси.

### Average Pooling

Вычисляется среднее значение скрытого слоя по временной оси.

### Attention Pooling

Для каждого скрытого слоя вычисляется обучаемый score:

```text
BiLSTM outputs
      ↓
Linear(hidden → 1)
      ↓
Softmax
      ↓
Attention weights
      ↓
Weighted sum
```

Таким образом, модель может назначать больший вес наиболее информативным словам/позициям в тексте.

## Эксперименты

В рамках проекта были исследованы следующие изменения.

### 1. Word2Vec vs FastText

Предобученные Word2Vec embeddings были заменены на FastText.

**Результат:** существенного улучшения качества не наблюдалось.

Это показывает, что для данной задачи преимущество subword-представлений FastText не является очевидным при использовании BiLSTM.

---

### 2. Maximum Sequence Length

Исследовались различные значения `max_len`.

Основное значение:

```text
64
```

Выбор связан с распределением длин текстов: подавляющее большинство текстов после токенизации укладывается в этот диапазон.

Уменьшение `max_len` позволяет сократить вычислительную нагрузку LSTM без заметной потери информации.

---

### 3. Layer Normalization

LayerNorm после embedding layer был добавлен для проверки влияния нормализации на стабильность обучения.

**Результат:** заметного изменения качества или стабильности обучения не обнаружено.

---

### 4. Pooling

Сравнивались:

* Max Pooling
* Average Pooling
* Attention Pooling

Average Pooling показал небольшой положительный эффект относительно Max Pooling.

Attention Pooling используется в текущей версии модели.

---

### 5. Optimizer and Learning Rate Scheduler

Рассматривались:

* Adam
* AdamW
* StepLR
* CosineAnnealingLR

AdamW + CosineAnnealingLR не дал однозначного улучшения.

---

### 6. Hidden Size

Исследовались:

```text
hidden_dim = 64
hidden_dim = 128
hidden_dim = 256
```

Наиболее стабильные результаты показал:

```text
hidden_dim = 128
```

Увеличение до 256 не дало ожидаемого прироста качества и в некоторых экспериментах приводило к ухудшению.

---

### 7. Dropout

Исследовался диапазон:

```text
0.3 – 0.5
```

Существенного влияния на итоговое качество обнаружено не было.

## Валидация

Для оценки используются:

### Accuracy

Доля правильно классифицированных объектов:

```text
correct predictions / total predictions
```

### Macro F1

Среднее F1 по всем четырем классам.

Macro-F1 используется дополнительно к Accuracy, поскольку позволяет отдельно учитывать качество классификации каждого класса.
